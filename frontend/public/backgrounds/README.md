# Background Images

Place your background images in this folder.

## Recommended Settings:

- **Format**: JPG or PNG
- **Resolution**:
  - For 4K displays: 3840 x 2160 or higher
  - For 1080p: 1920 x 1080 or higher
- **File size**: Optimize images to under 2MB for better loading

## Default Images:

- `monthly-bg.jpg` - Background for the monthly calendar view
- `weekly-bg.jpg` - Background for the weekly timeline view

## Configuration:

Edit `/src/config/backgrounds.js` to:
- Enable/disable backgrounds
- Set light or dark theme
- Adjust overlay opacity
- Change image paths

## Tips:

1. **Light backgrounds**: Use abstract patterns, watercolors, or light gradients
2. **Dark backgrounds**: Use dark gradients, space themes, or moody abstracts
3. **Overlay**: Increase opacity if text is hard to read
