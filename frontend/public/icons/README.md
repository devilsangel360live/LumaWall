# News Panel Icons

This folder contains animated GIF icons for the News Panel.

## Required Icons

Please add the following animated GIF files to this folder:

1. **top-stories.gif** - Icon for Top Stories section (e.g., fire, breaking news animation)
2. **politics.gif** - Icon for Politics category (e.g., scales of justice, government building)
3. **tech.gif** - Icon for Technology category (e.g., computer, circuit board, chip)
4. **gaming.gif** - Icon for Gaming category (e.g., game controller, joystick)
5. **sports.gif** - Icon for Sports category (e.g., soccer ball, various sports equipment)

## Recommendations

- **Size**: Icons should be square (ideally 64x64px or 128x128px)
- **Format**: Animated GIF with transparent background (if possible)
- **Animation**: Keep animations subtle and smooth (2-3 second loops work well)
- **File size**: Try to keep each icon under 100KB for fast loading
